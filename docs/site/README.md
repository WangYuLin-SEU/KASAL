# KASAL project website

English / 中文

This directory contains the bilingual KASAL project website: methods, software, datasets and paper citations.

## View locally

Download or clone the repository, then open `docs/site/index.html` in a browser. Keep the `assets` folder beside it. No build step, API key or server is needed.

GitHub displays the HTML source rather than rendering it as a website. Hosting is configured separately.

## Files

- `index.html`: page content and original SVG diagrams.
- `assets/site.css`: responsive layout and typography.
- `assets/site.js`: language switching, interface screenshots, installation tabs and copy controls.
- `assets/*.png`: existing KASAL logo and software screenshots.
- [ASSET_SOURCES.md](ASSET_SOURCES.md): sources and attribution.

The page stores only the language preference in the browser. It has no analytics or runtime API calls.

## 中文

本目录是 KASAL 中英文项目网页，介绍研究方法、软件、数据集与论文。

下载或克隆仓库后，用浏览器打开 `docs/site/index.html`，并保留同目录下的 `assets` 文件夹。无需构建、API 密钥或服务器。GitHub 会显示 HTML 源码；网页托管需另行配置。

修改正文请编辑 `index.html`，样式与交互分别位于 `assets/site.css` 和 `assets/site.js`。网页只在浏览器中保存语言偏好，不包含统计追踪或运行时 API 调用。
