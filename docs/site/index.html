01 / OVERVIEW

What KASAL studiesKASAL 研究什么

Rotational symmetry means that a rotation between 0° and 360° leaves an object unchanged. Geometric analysis compares shape; texture-aware analysis also checks appearance. Axis directions, orders and inter-axis angles describe this structure.物体旋转一个大于 0°、小于 360° 的角度后仍保持不变，就具有旋转对称性。几何分析比较形状，纹理分析还要求外观一致。轴的方向、阶数和轴间夹角共同描述这种结构。

KASAL studies how to represent and locate symmetry axes, how symmetry types relate to one another, and how this information helps pose estimation. It also infers symmetry when the type and order are unknown.KASAL 研究如何表示与定位对称轴、不同对称类型之间有什么关系，以及这些信息如何用于位姿估计。对于类型和阶数未知的物体，它也提供自动分析方法。

The methods can be used individually or together.这些方法可单独使用，也可组合使用。

02 / CAPABILITIES

Research methods and applications研究方法与应用

REPRESENTATION & LOCALIZATION结构表示与定位

Represent the full axis system with a few key axes用少量关键轴表示完整轴系

Given the symmetry type and order, a few key axes are enough to determine the full axis system. KASAL locates these key axes and derives the remaining axes from their geometric relationships. It uses ADI to fit geometry and ADI-C to incorporate texture.已知对称类型和阶数时，少量关键轴就能确定完整轴系。KASAL 先定位关键轴，再根据轴间的几何关系求出其余对称轴。几何定位使用 ADI，结合纹理时使用 ADI-C。

KASALv1 method figure: Wang & Luo, IEEE TIP 2024, Fig. 2, p. 6723 ↗KASALv1 方法图：Wang 与 Luo，IEEE TIP 2024，图 2，第 6723 页 ↗

KASALv1 studies axis localization for seven non-spherical symmetry types (Sec. III-A).KASALv1 的轴定位研究涵盖七类非球对称（第 III-A 节）。

RELATIONSHIPS & HIERARCHY结构关系与层次

Describe how symmetry types differ and relate描述对称类型的区别与联系

Symmetry types differ in the number, order and arrangement of their axes. KASALv2 describes eight canonical types and their geometric degeneration relationships in the Geometric Degeneration Hierarchy (GDH). These relationships also constrain the automatic search for symmetry type, order and axes.不同对称类型的轴数量、阶数和排列方式各不相同。KASALv2 用几何退化层次结构（GDH）描述八类典型对称及其退化关系。这些关系也为类型、阶数和轴系的自动推断提供约束。

GDH and the algorithm: Zhang et al., CVPR 2026, Fig. 2, p. 13868 ↗GDH 与算法图：Zhang 等，CVPR 2026，图 2，第 13868 页 ↗

SYMMETRY PRIORS FOR POSE位姿估计中的对称先验

Use consistent labels for equivalent poses为等价位姿使用一致的标签

A symmetric object can look the same in different poses. Its axes and rotational orders identify these equivalent poses, allowing training and evaluation to account for symmetry. In the KASALv2 pose experiment, equivalent ground-truth poses are assigned a consistent representative label.对称物体在不同位姿下可能看起来相同。对称轴和旋转阶数能确定哪些位姿等价，让训练与评测考虑这种等价关系。在 KASALv2 的位姿实验中，等价的真实位姿被统一到同一个代表标签。

POSE EQUIVALENCE位姿等价
R∼R S

S is a symmetry rotation of the object. R and R S are equivalent orientations and can share one representative label during training.S 是物体的一个对称旋转。R 与 R S 表示等价朝向，训练时可使用同一个代表标签。

Texture can distinguish orientations that have the same geometry but different appearances.纹理可以区分几何形状相同、外观却不同的朝向。

Infer symmetry type, order and axes from a mesh从网格推断对称类型、阶数与轴系

When the type and order are unknown, KASALv2 estimates the principal axis and its order, checks secondary axes using GDH, and reconstructs the full axis system. It automatically identifies the type, order and axes within the eight-type model.类型和阶数未知时，KASALv2 先估计主轴及其阶数，再根据 GDH 检验次级轴，重建完整轴系。它可在这八类对称中自动确定类型、阶数和对称轴。

The texture extension keeps the geometric axis directions and reduces rotational orders when appearance breaks some of the geometric symmetry.纹理扩展保留几何轴的方向，并在纹理破坏部分几何对称性时降低相应的旋转阶数。

03 / SOFTWARE & USAGE

Analyze meshes and save symmetry annotations分析网格并保存对称标注

Both methods compute axes automatically. Provide the type and order, or let the software infer them.两种方法都会自动计算对称轴。你可以给定类型和阶数，也可以让软件自动推断。

KNOWN TYPE / KASALV1已知类型 / KASALV1

Localize axes for a specified type指定类型后定位对称轴

Choose a specific symmetry type and provide n for prismatic or pyramidal types. KASALv1 then locates the axes using geometry or texture. Optional X/Y/Z fitting constrains an axis to a coordinate direction.选择具体的对称类型；棱柱、棱锥类型还需填写 n。KASALv1 根据几何或纹理定位对称轴。也可选择 X/Y/Z 拟合，将轴方向约束到指定坐标方向。

UNKNOWN TYPE / KASALV2未知类型 / KASALV2

Infer the type and localize the axes自动识别类型并定位对称轴

KASALv2 infers the symmetry type and order and locates the axes directly from the mesh. Texture can also be included in the analysis.KASALv2 从网格推断对称类型和阶数，并定位对称轴。分析时也可加入纹理信息。

The kasal-6d 2.x application includes both methods. The original 0.1.x application remains available, with separate installation instructions and licensing.kasal-6d 2.x 集成了这两种方法。原始 0.1.x 应用仍可使用，其安装方式和许可单独说明。

Desktop application桌面软件截图
INPUT输入

Load your meshes载入网格

In Setup, choose a dataset folder, preprocessing options and compute device. The GUI scans the folder and its subfolders for .ply and .obj meshes. Enable texture analysis to include available appearance information.在设置页选择数据集目录、预处理选项和计算设备。GUI 会扫描目录及子目录中的 .ply 和 .obj 网格。启用纹理分析后，也会使用可用的外观信息。

ANALYZE分析

Choose the analysis settings设置分析选项

Unlabeled objects use KASALv2 until you edit the type or n. Those edits select KASALv1. Forced X/Y/Z fitting also uses KASALv1 and requires a specific type. Analyze one object or run an incremental batch.未标注的物体默认使用 KASALv2；手动修改类型或 n 后，改用 KASALv1。强制 X/Y/Z 拟合也使用 KASALv1，并要求指定具体类型。可分析单个物体或运行增量批处理。

OUTPUT输出

Review and save results查看并保存结果

The GUI and saved jobs write *_sym_type.json beside the mesh, plus *_sym.ply when axes are found. The dataset runner saves BOP-style JSON for each object and JSON/CSV summaries in a separate output folder.GUI 与已保存任务将 *_sym_type.json 写入网格所在目录，存在对称轴时还会生成 *_sym.ply。数据集工具使用单独的输出目录，保存每个物体的 BOP 风格 JSON 和 JSON/CSV 汇总。

How the GUI and CLI choose the methodGUI 与 CLI 如何选择方法

In the GUI, unlabeled objects whose type and order have not been edited use kasalv2; this rule takes priority over the engine dropdown. Editing the type or order, or forcing X/Y/Z fitting, selects kasalv1. For CLI jobs with a specified type, set engine to kasalv1 and provide the type and n where required.在 GUI 中，物体未标注且类型、阶数未经手动修改时，使用 kasalv2；这条规则优先于引擎下拉框。修改类型、阶数或强制 X/Y/Z 拟合后，使用 kasalv1。CLI 任务如需指定类型，应将 engine 设为 kasalv1，并填写类型及所需的 n。

Both methods save *_sym_type.json. Objects with symmetry axes also receive *_sym.ply. Non-symmetric results are saved in JSON.两种方法都会保存 *_sym_type.json。有对称轴时还会生成 *_sym.ply；非对称结果保存在 JSON 中。 Usage details详细使用说明

Use Python 3.10 with compatible PyTorch and PyTorch3D versions.使用 Python 3.10，并安装相互兼容的 PyTorch 与 PyTorch3D 版本。

conda create -n kasalv2 python=3.10
conda activate kasalv2
python -m pip install -r https://raw.githubusercontent.com/WangYuLin-SEU/KASAL/3dba824747530bc6296b84b1d5ba6fa172610a18/requirements/torch-cpu.txt
python -m pip install kasal-6d==2.0.0
kasalv2 --help
Terminal终端
git clone https://github.com/WangYuLin-SEU/KASAL.git
cd KASAL
conda create -n kasal python=3.10
conda activate kasal
python scripts/install_deps.py full-cpu
python scripts/verify_pytorch3d.py
python demo_shape_meshes.py

Choose your runtime选择运行环境

The CPU example installs the documented 2.0.0 release. Source code reviewed for this page is version 2.0.1rc3. For CUDA, create a fresh environment and follow the matching GPU instructions.此 CPU 示例安装文档中的 2.0.0 正式版。本页核查的源码版本为 2.0.1rc3。使用 CUDA 时，请创建新环境，并按指南选择对应的 GPU 安装配置。

Installation guide完整安装指南
Migrating from kasalv2?从 kasalv2 包迁移？

Uninstall the standalone kasalv2 package first. It shares the kasal import directory with kasal-6d.请先卸载独立 kasalv2 包；它与 kasal-6d 共用 kasal 导入目录。

Launch the desktop GUI启动桌面 GUI

Replace PATH_TO_YOUR_MESH_DIRECTORY with your mesh folder. If running from source, use the shape or texture demo script below.将 PATH_TO_YOUR_MESH_DIRECTORY 替换为网格文件夹路径。从源码运行时，可使用下方的形状或纹理示例脚本。

kasalv2 "PATH_TO_YOUR_MESH_DIRECTORY"

From source:源码启动： python demo_shape_meshes.py or或 python demo_texture_meshes.py

Command-line jobs, datasets and outputs命令行任务、数据集处理与输出

Run a saved job运行已保存的任务

Terminal终端
python -m kasal.cli.run_job kasal/jobs/example_job.json

Process a dataset处理数据集

Terminal终端
python -m kasal.rotational_symmetry.run_dataset --input-dir INPUT --output-dir OUTPUT

GUI and command-line jobs save *_sym_type.json beside each mesh, plus *_sym.ply when axes are found. The dataset runner saves BOP-style JSON for each object and JSON/CSV summaries in a separate folder.GUI 与命令行任务将 *_sym_type.json 保存到各网格所在目录，存在对称轴时还会生成 *_sym.ply。数据集工具使用单独的目录，保存每个物体的 BOP 风格 JSON 和 JSON/CSV 汇总。
