# KASAL
Key-Axis-based Symmetry Axis Localization

We are excited to announce that our paper, "Key-Axis-based Localization of Symmetry Axes in 3D Objects Utilizing Geometry and Texture", has been accepted and published in IEEE Transactions on Image Processing (TIP). This work presents a novel method for localizing symmetry axes in 3D objects, utilizing both geometric and texture information. The approach identifies key axes in objects with geometric and texture symmetries, which improves pose estimation accuracy for a variety of vision tasks. The method has been demonstrated to perform robustly across a range of synthetic and real-world datasets.

The paper is now available at DOI: https://doi.org/10.1109/TIP.2024.3515801.

Additionally, we plan to release the complete dataset and the source code for personal use within the next one to two months. These resources will provide valuable tools for researchers and practitioners working on 3D object recognition and pose estimation.
